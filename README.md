# Natura Viva Gardens — App de gestión

App web (PWA) para gestionar mantenimientos de jardines, tareas, equipo y repostajes de combustible.

## Funcionalidades

- **Vista Mes** — calendario mensual con clientes por día y tareas de fin de semana
- **Vista Semana** — horario hora a hora (8:00–16:00) de lunes a domingo
- **Combustible** — calendario mensual para registrar repostajes
- **Equipo** — estado de Jose R., Alejo y Cristian con tareas pendientes
- **Tareas** — gestión global con asignación múltiple y selección masiva
- **Detalle de finca** — notas (multilínea con fotos) y tareas por cliente

## Cómo instalar la app en el iPhone

1. Abre **Safari** en el iPhone
2. Ve a la URL de la app publicada (la que te da GitHub Pages)
3. Toca el botón **Compartir** (cuadrado con flecha hacia arriba)
4. Desplázate y toca **"Añadir a pantalla de inicio"**
5. Confirma el nombre y toca **Añadir**

La app aparecerá como un icono en tu pantalla de inicio y funcionará como una app nativa, incluso sin internet.

## Datos

Los datos se guardan localmente en el navegador (localStorage). No se envían a ningún servidor.
